# LeetCode TypeScript Solutions

## Setup

```bash
npm install
```

## Running Tests

Run individual test:
```bash
npx ts-node test/1.TwoSum.test.ts
```

Run all tests:
```bash
npm run test:all
```

## File Structure

- `code/` - Solution files following format: `{LeetCodeNumber}.{ProblemName}.ts`
- `test/` - Test files following format: `{LeetCodeNumber}.{ProblemName}.test.ts`
